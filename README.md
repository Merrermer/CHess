# 中国象棋

这是一个基于PyQt5实现的中国象棋游戏。

## 功能特点

- 完整的中国象棋规则实现
- 直观的图形界面
- 棋子移动提示
- 游戏状态跟踪（将军、胜负等）

## 安装

1. 克隆本仓库
2. 安装依赖：
   ```
   pip install -r requirements.txt
   ```

## 运行

```
python -m chess_ai.main
```

## 游戏说明

- 红方先行
- 点击己方棋子选中，绿色圆点表示可移动位置
- 点击目标位置移动棋子
- 点击"重新开始"按钮可重置游戏

## 开发

该项目的代码结构如下：

- `chess_ai/`：主包
  - `chess/`：象棋相关模块
    - `piece.py`：棋子类定义
    - `board.py`：棋盘类定义
    - `renderer.py`：PyQt5渲染和UI实现
  - `main.py`：主程序入口
